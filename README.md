# cpp-pi
Will calculate pi with c++ using the [Monte Carlo Method](https://en.wikipedia.org/wiki/Monte_Carlo_method) not the fastest but is easy to understand.

**You can chose**
How many times it will place the dots,
How many decimal places it will output with,
If you want it to print what the calculation is on after each dotplacement.

**In the end it will output:**
What pi is,
How many dots were placed,
How many hits,
How many misses
and time it took to calculate.
